# MacGyver Gym Rat

Tell it the muscle you want to train and the one thing you have at home. It
recommends a real exercise from a catalog of 1324, with its real steps and its
GIF, or says plainly that nothing fits.

This Space runs the code of the project repository:
https://github.com/iamcroody/JoseJimenez-JuanYoung-AlbertoCervantes-DavidCuadros
(`final/deploy/`). It suggests; the decision is yours, and it does not replace a
trainer or a health professional.
